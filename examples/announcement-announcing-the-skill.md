Announcement post. The post that announced this repo.

I posted about my work on LinkedIn for 3 months. The reach barely moved.

If you write about your own work, you probably know this feeling.

So I read up on storytelling and built a format around Freytag's Pyramid: hook, rising action, climax, falling action, resolution.

My plan was to remember it and use it by hand. Then I realised I would be repeating the same steps every week. That is what Claude skills are for.

So I built one. You give it raw notes, and it drafts a story-style post under 250 words, short enough for a low attention span.

It follows examples of my own writing, so the post sounds like me and not like a generic AI draft.

It is open source: github.com/mahvashahmed/linkedin-storyteller

I will use it for the next few weeks and keep improving it.

If you do the same task more than twice, turn it into a skill. Every stuck point in your week is a chance to build something small.
